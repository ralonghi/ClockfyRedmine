# Regras de Desenvolvimento e Testes

Sempre que forem solicitadas novas implementações ou alterações no projeto:
1. **Cobrir com testes:** Criar novos testes unitários para cobrir as novas funcionalidades criadas ou ajustar os testes existentes afetados pelas alterações.
2. **Executar verificação:** Executar obrigatoriamente a suíte completa de testes (`python -m pytest`) antes de concluir a tarefa para garantir que todos os testes passem com 100% de sucesso.
